NASA Space Apps Challenge 2026

Space Mission Design Game

Design a mission, build the spacecraft, choose the launcher and the target point, launch and fly it step by step — and live with every trade-off between mass, power, science, data and budget.

Digital edition

Role HQ Manager, engineer, scientist and MCC: build graphs, consultant, journal, approvals Build calculator Mission → trajectory → build → checks → P, S, Δrating, Monte Carlo validator Campaign v1.5 15 steps: MCC, factory, science school, R&D/CML, tests, flights, final score

Tabletop edition (print and play)

Cards 63×88 mm sheets: launchers, instruments, events, missions — pick a deck and print Team board A3 Calculator rows, journal and mission slots for the table Tokens Money, marks and status tokens

Network mode (a team room over HTTP + SSE) needs the Node server: node server/index.mjs --port 8080 --data server/data, then open http://localhost:8080/app/lobby.html — opening the lobby from disk does not work, because its API calls need the server. Everything else runs directly in the browser — no build step, no npm packages. The team flow is written down in docs/NETWORK.md.
